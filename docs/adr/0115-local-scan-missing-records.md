# ADR-0115：本机扫描完成后标记缺失路径并保留记录

- 状态：Accepted
- 日期：2026-10-23
- 相关：ADR-0087、ADR-0023

## 决策

本机来源的完整目录扫描在登记完成后按目录核对仍在库的路径。根目录前后均须可读；目录权限或临时读取错误不作为删除证据。确认缺失的路径使用既有 `disposal='vanished'` 状态，从活动馆藏、预览与资料处理队列退出，保留资料、来源和个人记录，不物理删除媒体或账本行。

文件返回原路径时沿用既有 upsert 恢复同一记录。重命名导致新路径登记时，不凭大小或名称相似度自动合并身份。个人记录接回仍使用 ADR-0087 的既有判据和人工入口。远程来源的对账与删除仍由资源同步执行；单件摄取、未完成扫描与离线根不执行本步骤。

## 复用与验证

扫描和资源同步共用逐目录存在性判据，保留大小写不敏感语义与读取失败保护。临时媒体与账本覆盖改名、删除、原路径恢复、根不可读和扫描断点续跑；不以真实库写入作为开发验证。
