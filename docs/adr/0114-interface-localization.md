# ADR-0114：在 React 呈现边界共享界面词条

- 状态：Accepted
- 日期：2026-10-23
- 关系：扩展 ADR-0031 的单一 React 运行时，不改变数据库语言或协议。

## 决定

主界面与独立页面使用 `@peach/i18n` 自动 JSX 入口。该入口调用原有 React 19.3.1 的 `jsx`、`jsxs` 与开发期 `jsxDEV`，只在构造元素前翻译词条目录中的呈现字符串及辅助技术属性，不引入第二套组件运行时。路径、表单值、标识符与请求字段不变，数据库内容不改写。

英文为默认界面语言，简体中文保留原文；另提供繁体中文、西班牙语、法语、德语、巴西葡萄牙语、日语、韩语与越南语的离线生成目录。选择保存于浏览器本来源的 localStorage，切换时重新加载。页面根节点同步 `lang`。语言入口复用现有 Select 控件，首启、登录、错误与配置页均可选择。代码、样式、文本编辑值不翻译；未登记的自定义文案回退英文，未知外部文字保留原文。

英文目录由 `frontend/src/i18n/en.generated.json` 与人工优先词条 `en.json` 组成，以原始中文文案为键。`inventory.json` 保存公开源代码的提取位置；离线检查拒绝缺词条或参数丢失。同次新增界面文案应登记词条。模板按固定文字的长度匹配，支持组合消息与快捷键后缀；动效读数在拆字符之前翻译。

命令式 HTML、Toast、右键菜单和门户使用同一份 DOM 呈现适配器，观察新节点、文字与可访问属性的更新。简体中文目录补齐自定义英文控件，其余语言覆盖公开原文与自定义控件。输入值、代码、可编辑内容及标记的媒体标题不进入该边界；原生 option 的隐式 value 在改显示文字前固定为原值。观察器不改变业务状态、属性键、请求参数或存储内容。

## 边界与验证

这是一层呈现适配，公开源代码中的界面文字、组合消息与命令式 DOM 纳入同一目录；外部服务返回且未登记的文字保留原文。机器翻译候选来自固定公开 Git revision 与明确登记的通用自定义控件文案，主界面词汇由人工覆盖，运行时不连接翻译服务。动态媒体数据和编辑值不改写。

Vitest 与已有浏览器夹具显式选择中文，英文默认值、参数、辅助属性及表单值隔离另行验证。浏览器在桌面及 390×844 视口验证英文表单与语言切换。构建仍生成同一份主包与独立页面包，不增加运行依赖。
