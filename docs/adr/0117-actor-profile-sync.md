# ADR-0117：演员资料与实体独立同步

状态：采用。

## 决定

演员页右侧资料区展示生涯、生日与按当天计算的年龄、身高、三围、胸部类型、国籍、族裔和眼睛／头发颜色。扩展 ADR-0069 的资料区字段；原有女优资料作为缺省值，保留出道与标签信息。

StashDB 只读查询返回的确定字段保存在实体 `metadata_json.stashdb_profile`，手工修订保存在 `actor_profile_edits`，读取优先使用手工值。清空字段表示明确留空，使用来源资料表示删除覆盖。来源同步不覆盖手工修订，不把候选升级为已复核。

StashDB 别名以独立来源进入 `entity_alias`，重新同步替换本来源条目，保留手工与其它来源。名称内部空格属于身份写法，批量输入只按逗号或换行分隔。

馆藏处理新增演员与厂牌两个独立阶段，直接遍历现有实体。已绑定 ID 按 ID 读取，未绑定只接受唯一且无歧义的名称／别名匹配；冲突保留待用户处理。不读取媒体文件、不查询作品、不纠正作品名单。任务复用馆藏锁、节流、停点和恢复记录，已成功实体在同一任务恢复时跳过。显式重新同步不使用日常扫描的完成缓存。
