# ADR-0116：RSS 下载与 debrid 渠道

状态：采用。

## 决定

关注管理的「RSS 下载」接受用户提供的公开 HTTP/HTTPS RSS/Atom 地址，复用订阅来源、条目去重和调度。条目可以没有番号；保存订阅条目不创建馆藏资产。订阅更新只获取列表，只有用户点击链接旁的 debrid 图标才调用 AllDebrid 或 Real-Debrid 准备下载。

密钥只存于本机 secrets，使用官方接口的 Authorization 头，读接口只返回配置状态。支持域名来自渠道的连接检查；已知不支持的链接不显示该渠道图标。准备完成后，单文件直接交给浏览器，或写入该渠道已配置的目录；多文件由用户逐项选择。容器目录必须事先存在，并由部署者挂载。

本机 state 保存任务、远端身份和部分下载的验证器。取消停止本机准备或传输，不删除远端任务。进程恢复继续查询已提交的远端身份；目录下载在 ETag 与 Range 一致时续传，完成前使用独立临时文件，发布时排他创建，避免覆盖现有文件。单工作者、请求间隔、响应大小、条目数、文件数和磁盘余量均有界。

## 网络与验证

解析器只接收已取得的字节，不自行联网；拒绝 DTD/实体。订阅、种子和文件的每个跳转都检查公开目标，拒绝本机、私网和非网页协议，不向下载目标转发渠道密钥。行为测试使用临时账本、虚构订阅和模拟官方接口；桌面及手机浏览器验证图标、目录配置、成功回执和布局。真实付费账号、宿主机挂载权限与公网下载速度需部署后验证。
