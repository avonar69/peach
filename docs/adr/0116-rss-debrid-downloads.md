# ADR-0116：RSS 下载与 debrid 渠道

状态：采用。

## 决定

关注页「全部」包含 RSS 更新分区，复用管理页的图文卡片与下载动作；有创作者、来源、题材、标签或时长筛选时保持原筛选范围。每个 RSS 来源默认开启 6 小时自动更新，用户可单独关闭或保存 15 分钟至 7 天的间隔。RSS 到期检查复用现有调度实现，15 分钟节拍按来源到期时间选择，不触发非 RSS 来源或作品资料后继；关闭自动更新仍保留条目与手工刷新。

关注管理的「RSS 下载」接受用户提供的公开 HTTP/HTTPS RSS/Atom 地址，复用订阅来源、条目去重和调度。条目可以没有番号；保存订阅条目不创建馆藏资产。订阅更新只获取列表，只有用户点击链接旁的 debrid 图标才调用 AllDebrid 或 Real-Debrid 准备下载。

密钥只存于本机 secrets，使用官方接口的 Authorization 头，读接口只返回配置状态。支持域名来自渠道的连接检查；已知不支持的链接不显示该渠道图标。准备完成后，单文件直接交给浏览器，或写入该渠道已配置的目录；多文件由用户逐项选择。容器目录必须事先存在，并由部署者挂载。

本机 state 保存任务、远端身份和部分下载的验证器。取消停止本机准备或传输，不删除远端任务。进程恢复继续查询已提交的远端身份；目录下载在 ETag 与 Range 一致时续传，完成前使用独立临时文件，发布时排他创建，避免覆盖现有文件。单工作者、请求间隔、响应大小、条目数、文件数和磁盘余量均有界。

## 保存期限与下载后导入

RSS 条目默认永久保存。来源可设置天、月或年的滚动期限，以首次保存时刻计算；月和年按公历边界截取有效日期。后台 RSS 节拍、正常拉取、304 与保存期限设置均执行到期清退；停用自动更新的来源仍按期限清退。清退只移除标题、图片地址及下载地址等内容，条目标识、首次保存与来源内的身份映射作为最小去重记忆保留。文章的稳定标识或公开地址决定合并，合并保留原始首次保存时刻并合并链接和预览。更新不能复活已到期条目。

下载与扫描任务共用 `TaskPopup` 框体和 Sonner 后台任务栈。下载浮层在路由根观察本机记下的任务标识，刷新可恢复观察；准备链接、目录传输、取消、导入与重试分别反映真实状态。浏览器接管直链后的字节进度不可由 Peach 观测，浮层保持链接就绪语义。服务端目录下载完成后，渠道级自动导入开关可声明 `debrid-import` 持久后继。目录必须能映射到已声明媒体根，账本仍保存 Windows 路径；单文件登记复用 `ingest_path`，资料和预览复用带 `asset_ids` 的处理管线。下载终态独立于导入终态；资料失败、取消或重试保留文件，互斥扫描期间等待，重启保留待办。

## 网络与验证

条目按标题、来源与时间、主缩略图、预览图库及下载链接展示。正文只用于解析图片和链接，页面不插入来源 HTML 或说明文字；预览区的多张图片各自保留原图链接。图片保存经过公开地址校验的 URL，浏览器延迟加载并抑制 Referer，加载失败时移除该图。来源级「隐藏不支持的链接」默认关闭，开启后只展示已配置渠道确认支持的主机以及可处理的磁力／种子地址，原始链接序号保持不变。首次迁移清空 RSS 条件请求标记，以便下次获取补齐已有条目的图片。

解析器只接收已取得的字节，不自行联网；拒绝 DTD/实体。订阅、种子和文件的每个跳转都检查公开目标，拒绝本机、私网和非网页协议，不向下载目标转发渠道密钥。行为测试使用临时账本、虚构订阅和模拟官方接口；桌面及手机浏览器验证图标、目录配置、成功回执和布局。真实付费账号、宿主机挂载权限与公网下载速度需部署后验证。
