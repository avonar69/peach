# Tdarr 媒体扫描选项取证

取证日期：2026-10-26。来源：[Tdarr 官方 Library Options Button](https://docs.tdarr.io/docs/library-setup/library-options/)。本文件为人工取证笔记，没有保存可重抓并逐字核验的上游原文，因此不登记进 `docs/reference-sources.json`。

**实测文档**：官方页面将 Scan (Find new) 定义为遍历来源目录、发现尚未扫描的文件，并移除来源目录中已经不存在的文件记录；Scan (Fresh) 清空该库数据库后扫描全部文件。取证通道为网页检索取得的官方正文。运行中的 Tdarr 界面与实际扫描性能：未取得，不声称复现其实现或速度。

**Peach 方案**：借用查找新增与完整扫描的明确区分，以查找新增作为数据管理主动作；完整扫描放在菜单并确认。沿用 Peach 的来源枚举与新增标识，将后续昂贵处理限定到本次新视频。目录枚举仍覆盖所有文件，并不表示对每部影片重新探测或联网匹配。删除与改名继续沿用 Peach 的本机缺失标记和远程资源同步机制；完整扫描保留个人记录和已保存图片，不复制清空数据库的做法。

仅参考公开行为语义，没有复制 Tdarr 源码或引入其依赖。验收使用隔离库与模拟采集边界；真实部署规模的耗时未取得。
